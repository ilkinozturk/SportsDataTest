Testing Instructions

  1. Open your browser's Developer Console (F12)
  2. Navigate to team-stats.html?teamId=836
  3. Click on the "Goals" tab
  4. Look for console logs starting with "[GoalsDisplay]"
  5. Click on Home/Away filters in Timing Analytics section
  6. Check console for:
    • "[GoalsDisplay] Timing filter change event received: home"
    • "[GoalsDisplay] updateTimingAnalytics called with filter: home"
    • "[GoalsDisplay] Home timing data: {...}"

What Was Fixed

The issue was that updateGoalsStatistics was passing the general venue filter (overall/home/away) to updateTimingAnalytics instead of the timing-specific filter.

Now it correctly retrieves the timing filter from StateManager:

// Before:
this.updateTimingAnalytics(statistics, filter);

// After:
const timingFilter = global.TeamStatsStateManager?.get('filters.timing') || 'overall';
this.updateTimingAnalytics(statistics, timingFilter);

Troubleshooting

If the timing analytics still don't update:

  1. Check if EventBus is initialized: Type window.TeamStatsEventBus in console
  2. Check if StateManager is initialized: Type window.TeamStatsStateManager in console
  3. Verify modules are loaded: Type window.TeamStatsGoalsDisplay in console
  4. Check for errors in console
