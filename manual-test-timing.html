Manual Test for Timing Analytics

📋 Test Procedure

Follow these steps in order on the team-stats.html page:

Step 1: Open team-stats.html

Navigate to: http://localhost:3005/team-stats.html?teamId=836

Step 2: Open Console (F12)

Open browser developer console

Step 3: Wait for page to load

Look for this console log:

[team-stats.js] Emitting data:team:loaded event [GoalsDisplay] data:team:loaded event received [GoalsDisplay] lastStatistics set, sample data: { homeGoals0_15: 4, awayGoals0_15: 1, goals0_15: 5 }

Step 4: Navigate to Goals tab

Click on the "Goals" tab

Step 5: Test manual update

Run this in console:

// Force manual update with home filter if (window.TeamStatsGoalsDisplay && window.globalStatistics) { console.log('=== Manual Update Test ==='); // Set lastStatistics if not set if (!window.TeamStatsGoalsDisplay.lastStatistics) { window.TeamStatsGoalsDisplay.lastStatistics = window.globalStatistics; console.log('✓ lastStatistics was set manually'); } // Check data exists const stats = window.TeamStatsGoalsDisplay.lastStatistics; console.log('Home data check:', { homeGoals0_15: stats.homeGoals0_15, homeGoals16_30: stats.homeGoals16_30, homeGoals31_45: stats.homeGoals31_45, homeGoals46_60: stats.homeGoals46_60, homeGoals61_75: stats.homeGoals61_75, homeGoals76_90: stats.homeGoals76_90 }); // Call update directly console.log('Calling updateTimingAnalytics with home filter...'); window.TeamStatsGoalsDisplay.updateTimingAnalytics(stats, 'home'); // Check DOM setTimeout(() => { const bar = document.getElementById('goals0_15ScoredBar'); console.log('Bar width after update:', bar ? bar.style.width : 'BAR NOT FOUND'); }, 100); } else { console.error('GoalsDisplay or globalStatistics not found!'); }

Step 6: Check timing filter buttons

Click on Home/Away buttons in Timing Analytics section and check console for:

[team-stats.js] setTimingFilter called with: home [GoalsDisplay] Timing filter change event received: home [GoalsDisplay] Home timing data: {...} [GoalsDisplay] Timing totals: {...}

⚠️ Important Notes

  • Make sure you're on the Goals tab to see Timing Analytics
  • The data:team:loaded event must fire for lastStatistics to be set
  • Home/Away data exists in the API response (confirmed)
  • Field names are correct (homeGoals0_15, awayGoals0_15, etc.)
